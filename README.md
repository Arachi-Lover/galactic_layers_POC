# galactic_layers_POC

This is a proof of concept (POC) plugin to demonstrate the possibility of using the map mechanics to create pseudo "layers" to the Milky Way galaxy map of Endless Sky.

This is inspired by https://eldenring.wiki.fextralife.com/Interactive_Map , and could be used as a means to get more "room" for story instances, alternate time periods for factions/stories that involve time travel, or other such ideas.

The plugin creates 3 separate galaxies, each using a different galaxy image (generated via applying color filters to the original image). The alternate galaxies are shifted by 30000, 60000, and 90000 over the initial value in the galaxy `pos` definition.

Asteroids, minables, trade and fleets were removed from the copy galaxy. Galaxy labels (i.e. "Earth", "Wanderers") were also omitted, as were all landables. Additionally, one of the galaxies had all hyperspace links removed.

To access the separate galaxies, head to `Sagittarius A*`, where wormholes link to each of the other galaxies. To map out all of the galaxies at once, land on `"Kalbai"` in Bunrodea space (it is the landable planet closest to `Sagittarius A*`, for ease of testing).
